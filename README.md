# MiniNet

MiniNet is a browser-based networking platform that allows users to create, reserve, manage, and access custom MiniNet domains and services.

The project provides an alternative domain routing system that works through a browser extension, allowing users to build websites, communities, and services within the MiniNet ecosystem.

Features include:

* Custom domain routing
* Reserved domains
* Permanent domains
* Temporary domains
* Community-hosted websites
* Browser extension support
* Domain management tools
* Local and hosted environments
* Custom MiniNet services
* User-controlled domain ownership

MiniNet is designed to provide a flexible and easy-to-use environment for creating and accessing custom web experiences.
